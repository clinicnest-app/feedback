# ClinicNest – feedback and support

ClinicNest is a free clinic records app for small clinics: <https://updates.clinicnest.app/>

This is the place to tell us what does not work, what is missing, or to ask a question.

| I want to … | |
|---|---|
| report something that does not work | [Bug report](https://github.com/clinicnest-app/feedback/issues/new?template=bug.yml) |
| suggest something | [Feature request](https://github.com/clinicnest-app/feedback/issues/new?template=feature.yml) |
| ask how to do something | [Support question](https://github.com/clinicnest-app/feedback/issues/new?template=support.yml) |

No GitHub account? Write to **support@clinicnest.app** – in ClinicNest: your name (top right) → *Feedback and support*.

## Please never post patient information

Everything written here is public. Do not include names, phone numbers, patient IDs, photos of prescriptions
or screenshots that show a patient. Describe the problem with made-up data, or send it by email instead.

The ClinicNest version is shown in ClinicNest under *Settings → About*.
